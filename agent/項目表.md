## 數據流

```
unit files (/etc/systemd/system, /run/systemd/system, /usr/lib/systemd/system)
   ↓ systeme-units (parse + specifier expand)
UnitConfig
   ↓ systeme-core (dependency graph → transaction jobs)
JobQueue
   ↓ systeme-manager (schedules)
systeme-exec (spawn via fork/exec, track via cgroup|subreaper) ⇄ kernel
   ↑ IPC (unix socket, JSON line protocol)
systemctl / journalctl CLI
```

## 模式探測 (啟動時)

1. euid==0 且可寫 /run/systemd → 系統模式 (system slice, /run/systemd/private)
2. 否則有用戶 runtime dir → 用戶模式 ($XDG_RUNTIME_DIR/systemd/private)
3. cgroup 探測: /sys/fs/cgroup 可寫且 unified → v2; 混合 → v1; 都不行 → none (subreaper+proc 掃描)
4. 永不要求 PID==1; 但若確實是 PID 1 也能正常工作 (信號處理器相同)
